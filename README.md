# 🌐 Networking-CLI

**Networking-CLI** es una herramienta ofensiva/defensiva potenciada con **Inteligencia Artificial** para escaneo de puertos, sniffing, análisis de tráfico, detección de vulnerabilidades y automatización de tareas de red. Todo desde una interfaz CLI con banner épico y estilo cyberpunk.

> ⚠️ **Uso ético y legal solamente.** El autor no se responsabiliza por mal uso.

## 🚀 Características
- 🧠 **IA integrada** (detección de patrones, predicción de tráfico malicioso)
- 📡 Escaneo de puertos (TCP/UDP) con optimización inteligente
- 👃 Sniffer de paquetes con análisis en tiempo real
- 🛡️ Recomendaciones automáticas de seguridad
- 🎨 Banner CLI con efectos y colores
- 💻 Cross-platform: **Windows** y **Linux**
- ⚡ Velocidad mejorada por heurística de IA

## 📦 Instalación

### Linux
```bash
git clone https://github.com/Falconmx1/Networking-Cli.git
cd Networking-Cli
chmod +x install.sh
sudo ./install.sh

Windows (PowerShell como Admin)
powershell

git clone https://github.com/Falconmx1/Networking-Cli.git
cd Networking-Cli
.\install.ps1

🕹️ Uso básico
bash

networking-cli --scan 192.168.1.0/24
networking-cli --sniff --interface eth0
networking-cli --ai-analyze capture.pcap
networking-cli --help

🧠 Módulo de IA

    Clasificación de tráfico benigno/maligno

    Predicción de ataques (DDoS, ARP spoofing)

    Auto-recomendaciones de iptables/nftables

    Python 3.10+

    Scapy, Nmap, TensorFlow Lite (modelo liviano)

    Colorama, Rich para UI
